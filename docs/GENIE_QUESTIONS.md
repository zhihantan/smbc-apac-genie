Generated by `src/50_genie/build_question_bank.py` from the agents' authoring files (`genie/<slug>/space.yaml`, benchmarks, evaluation reports), the curated text in `genie/_question_bank.yaml` and a live capture on the demo workspace (4 Oct 2026). All data is **synthetic** (no real clients, people or figures) and as of **30 Sep 2026**, the close of H1 FY2026. Amounts are USD unless a question asks for local currency.

In total: **11 agents**, **88 starter questions** (75 ✅ / 13 ⚠️) and **216 tested benchmark questions** (213/216 passed in the last evaluation). The same list is in `docs/genie_questions.csv`.

## How to use this guide

### Asking good questions

- **Use full names.** Say "Kinokawa Precision" ("Kinokawa" also matches Kinokawa Heavy Industries), "Meridian Agri Holdings" ("Meridian" also matches Meridian Investment Corporation) and "Sunda Energi Nusantara (Jakarta)" for the Jakarta entity. "Tanaka Chemical" and "Tanaka Chemical Group" are two different groups.
- **Pin the date for point-in-time figures.** Balances, early-warning bands and exposure work best with "today" or "as at 30 Sep 2026". Today in this demo is 30 Sep 2026; the agents never use the computer's clock.
- **Use Japanese fiscal-year terms.** FY2026 = Apr 2026 – Mar 2027. H1 FY2026 = Apr – Sep 2026 (closed on 30 Sep 2026); Q2 FY2026 = Jul – Sep 2026; Q3 FY2026 = Oct – Dec 2026. "This year" means FY2026 to date, and year on year compares the same months of FY2025.
- **Say what you want to see.** Name the grouping, the period and the size of the list ("by coverage office", "since April 2025", "top 20", "with the RM and days open"). A vague question gets a reasonable answer, but not always the cut you had in mind.
- **Follow up in the same conversation.** "Now only Singapore", "show it by month", "the same for Tanaka Chemical". Start a new conversation when you change topic.
- **Check the SQL.** Every answer shows the SQL Genie ran. Open it to see the filters, the metric views (the governed business definitions) and, where used, the trusted SQL function behind the answer.
- **Banking terms work.** CASA (current and savings accounts), RoRWA (return on risk-weighted assets), RAROC (risk-adjusted return on capital), EWS (early-warning score), DPD (days past due), SCF (supply chain finance), RCF (revolving credit facility), LTV (loan-to-value), WL (watchlist), "headroom", "utilisation". Amounts are USD unless you ask for local currency.
- **Good to know about the data.** It is synthetic. The brief's "8% RoRWA hurdle" is configured as 1.2% (with RAROC 12% and ROE 10%), and "below hurdle" means the configured Below-Hurdle flag. Covenant waivers are always 0. AI forecasting (`ai_forecast`) is disabled on this workspace, so forward cash-flow projections use the deterministic seasonal fallback. Two realistic entity-resolution leftovers remain on purpose: an entity named "SUNDA POWER HOLDINGS TRADING (HONG" in the Kinokawa group and a typo'd "Kinokawl Precision (Jakarta) PT".

### Genie One and the agents

- **Genie One** (formerly Databricks One, renamed in 2026) is the simplified Databricks UI for business users: "a single entry point for interacting with data and AI without navigating technical concepts like compute, queries, models, or notebooks". Open it at <https://my-workspace.cloud.databricks.com/one>. Docs: <https://docs.databricks.com/aws/en/genie-one/>.
- **Ask without picking an agent.** Chat in Genie One "first searches available Genie Agents for a match, then searches across dashboards, queries, and metric views" (<https://docs.databricks.com/aws/en/genie-one/chat>). A business user can type any question from this guide there, and Genie One routes it to one of the 11 agents.
- **Routing in this workspace.** The demo workspace also holds about 20 Genie Agents from other demos (for example "KYC Analyst Genie" and "Credit Risk Genie"), and the docs warn that many agents can reduce routing accuracy. Distinctive wording helps (client names, "APAC", "early-warning band"). If an answer comes from another agent, open the APAC Genie agent directly with the links below.
- **Access.** "Consumer access, the least-privileged option, is enough for Genie One chat"; the user also needs CAN USE on a SQL warehouse. Each agent additionally needs its own permission (CAN RUN or higher) and Unity Catalog access to its data. In this demo the agents are not shared with anyone yet.

### Reading the results

- **Starter questions** were asked live through the Genie Conversation API and compared with the benchmark each one paraphrases. ✅ = Genie's rows equal the benchmark's expected rows (same number of rows, values to 4 significant digits) on every column both answers show; Genie may add columns, or leave out benchmark columns the starter does not ask for (the note lists them). ⚠️ = answered with SQL, but the rows or values differ (the note says how). ❌ = an error, or an answer without SQL.
- **Benchmark questions** (the tested wordings under each theme) are graded in the agent's evaluation: ✅ passed, ⚠️ missed in the last run. The 3 that missed are listed under *Phrase with care* with a safer wording that was re-tested live.
- **Answer** is the result of the benchmark's expected SQL (the governed query that defines the right answer), re-run on the workspace for this guide: the number of rows and the first rows. Your live answer should show the same figures.
- **Good follow-ups** were asked live in the same conversation as their starter question; ✅ = Genie answered with SQL that kept the context (for example the same client).
